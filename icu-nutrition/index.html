§1栄養療法の基本方針

この章で決めることは、誰に栄養療法を考えるかと、その順番です。栄養は ICU 死亡率を下げうる数少ない介入の一つで、開始の遅れは抗菌薬の遅れと同じように問題にします。

1-1. 対象と原則

  • 対象は全ICU入室患者です。特に入室期間が48時間を超える見込みの患者で重要になります。当院
  • 原則は If gut works, use it!（腸が使えるなら使う）です。
  • 腸蠕動音を開始の指標にしないでください。蠕動音が聞こえないことは、栄養を始められないことを意味しません。
  • 優先順位は 経口 ＞ 経鼻胃管（NG） ＞ 経鼻空腸管（NJ） ＞ 静脈栄養（PN） です。

§7トラブルに対応する

この章では、胃残・消化管運動・下痢・便秘への対応を決めます。共通する原則は、できるだけENを止めないことです。

7-1. 胃残量（GRV）の考え方

当院標準

当面は、6・14・22時の測定と、250 mL/回以上での医師コールを続けます。最新の指針を踏まえて、測定をやめるかどうかを院内で検討しています。当院

落とし穴

250 mL/回を超えても、嘔吐・腹部膨満・腹痛・画像・乳酸が落ち着いていれば、胃残だけでENを止めないでください。日本版2016・ESPEN 2023 の目安は 500 mL で、当院の 250 mL はそれより低い値です。250 mL は「減速して相談する合図」と考えます。胃残が続けて多いときは、蠕動促進薬 → 幽門後投与へ進みます。

§9栄養剤の選び方と基礎知識

この章では、栄養剤を選ぶ手順と、栄養剤の分類を整理します。製剤の選択は栄養管理の最後の一手で、その前に「始められるか」「どこから入れるか」「どれだけ入れるか」が決まっている必要があります。当院の標準はペプタメン（消化態）ですが、選ぶ理由は「消化態だから」ではありません。

9-1. 栄養剤を選ぶ前に決める5つのこと

  1. 始められるかを判断する
    ICU入室後48時間以内の開始を目指します。腸蠕動音を開始の指標にしません。開始基準は §2 です。当院
  2. ルートを選ぶ
    経口 ＞ NG ＞ NJ ＞ PN。胃残が多く薬剤でも改善しない、または誤嚥リスクが高ければ W-ED チューブで幽門後へ（§3）。
  3. 目標量を決める
    蛋白 1.3 g/kg（実体重）/日が第一優先、カロリー 25〜30 kcal/kg/日が第二優先。NUTRIC スコア 5点以上を高リスクとします（§4・§5）。
  4. 栄養剤を選ぶ
    急性期は「蛋白は多め、カロリーは控えめ」になるので、少ない容量で蛋白が多いペプタメンシリーズを選ぶことが多くなります。ICU所属の管理栄養士と相談して決めます。
  5. 病態で微調整する
    高K血症が制御できない腎障害 → リーナレン、血糖が下がらない → 低GI製剤、下痢が続く → ペプチド製剤・プレバイオティクス配合・半固形化製剤（§9-7）。
ICU滞在48時間以上は全例で栄養療法を考える

ICUに48時間以上いる患者は、全例で栄養療法を検討します。入院前に絶食が長かった患者は、栄養剤を選ぶより先にリフィーディング症候群のリスクを評価してください（§4-2）。ESPEN

9-2. まず窒素源で分ける

栄養剤は、窒素源（たんぱく質がどこまで分解されているか）で分類します。大きくは、蛋白源が天然食品由来の天然濃厚流動食と、成分栄養・消化態・半消化態からなる人工濃厚流動食の2つです。天然濃厚流動食は消化能力が落ちた患者には向かないので、ICUで選ぶのは人工濃厚流動食のどれかになります。

分解が進むほど消化を必要としませんが、粒子の数が増えるぶん浸透圧は高くなり、脂質やビタミン・ミネラルは乏しくなります。反対に半消化態は消化を要しますが、浸透圧が低く、脂質もビタミン・ミネラルも充足しています。

＋α　ホエイは胃で固まらない

表の窒素源にあるカゼイン・ホエイ・大豆・卵白は、蛋白質の素材です。ホエイ（乳清蛋白）は牛乳の蛋白からカゼインを除いた水溶性の画分で、ヨーグルトの上澄みに含まれる蛋白がこれにあたります。カゼインは胃酸に触れると固まってカード（凝乳塊）を作りますが、ホエイは胃内でも溶けたままで、カゼインより胃排出が速いという特徴があります。ペプタメンシリーズがホエイ由来ペプチドを使っているのは、この「固まらず胃に残りにくい」性質を利用するためです。

9-3. 重症患者の基本は標準的な半消化態

標準ポリメリック製剤が基本　ASPEN2016

一般的な重症患者には、標準的な半消化態（ポリメリック）製剤が推奨されています。術後の外科ICU患者（上部消化管・頭頸部癌など）では、アルギニン＋魚油＋ヌクレオチドを含む免疫強化製剤で感染が減り（RR 0.78、95%CI 0.64–0.95）、在院日数が 2.23日短くなりました（35試験）。内科ICU患者、特に敗血症での利益は確認されていません。ARDS では EDEN-OMEGA 試験でω-3脂肪酸の単独投与が有害の傾向を示したため、標準製剤を使います。特殊組成の製剤は、糖尿病・腎障害・消化管不耐など患者側に明確な理由があるときに選びます。

つまり「下痢だからまず消化態へ変更」ではなく、原因検索と薬剤調整が先で、製剤変更はその後の選択肢です（§7-4）。下痢には分類よりも浸透圧と投与方法の影響が大きく、浸透圧の高い製剤（エレンタール 755・リーナレン 720〜730・イノラス 670 など）は浸透圧性下痢の一因になります。ボーラス投与より持続投与のほうが下痢は少なくなります（RR 0.42、95%CI 0.19–0.91）。ESPEN

§17症例の解決

NAD 0.12 μg/kg/分で乳酸が改善しているので、循環は開始基準を満たします。腸蠕動音が聞こえないことは開始を妨げません。一方、10日以上の摂食不良は表6の「1つ以上」に、BMI 17.5 は「2つ以上」の項目に当てはまり、リフィーディング高リスクです。

入室48時間以内に、経鼻胃管からリフィーディング予防プロトコール（ペプタメンインテンス、医師指定の低速で開始、5 mL/時ずつ増量）を選び、ビタメジンを1週間投与し、開始後72時間は P・Mg・K を毎日確認します。NAD が 0.1 μg/kg/分以上のあいだは増量を見合わせ、腹部膨満や乳酸の再上昇があればENを止めて腸管虚血を評価します。
