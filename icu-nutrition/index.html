§1栄養療法の基本方針

この章で決めることは、誰に栄養療法を考えるかと、その順番です。栄養は ICU 死亡率を下げうる数少ない介入の一つで、開始の遅れは抗菌薬の遅れと同じように問題にします。

1-1. 対象と原則

  • 対象は全ICU入室患者です。特に入室期間が48時間を超える見込みの患者で重要になります。当院
  • 原則は If gut works, use it!（腸が使えるなら使う）です。
  • 腸蠕動音を開始の指標にしないでください。蠕動音が聞こえないことは、栄養を始められないことを意味しません。
  • 優先順位は 経口 ＞ 経鼻胃管（NG） ＞ 経鼻空腸管（NJ） ＞ 静脈栄養（PN） です。

1-2. 略語

この章では、ENを始めてよい条件と、遅らせるべき状況を決めます。目標は ICU 入室後48時間以内の開始です。JCCNG2024 CQ1-5

2-2. 昇圧薬を使っているとき

昇圧薬が必要な患者では、腸管の血流が落ちている可能性があります。そこに栄養剤を入れると腸管の酸素需要が増え、まれに非閉塞性腸管虚血を起こします。一方で、少量の栄養は腸粘膜を保つ働きがあります。この釣り合いをどこで取るかが論点です。

当院標準

  • エネルギー：25〜30 kcal/kg（実体重）/日　…第二優先
  • 蛋白を優先し、カロリーは控えめでもよい（permissive underfeeding）

当院

5-2. 急性期の上げ方

急性期には、体が自分の組織を分解して作るエネルギー（内因性エネルギー）があります。そこに外から全量を足すと過剰になり、高血糖や、細胞の自己修復（オートファジー）の抑制につながると考えられています。そのため、最初の数日は少なめから始めます。

§7トラブルに対応する

この章では、胃残・消化管運動・下痢・便秘への対応を決めます。共通する原則は、できるだけENを止めないことです。

7-1. 胃残量（GRV）の考え方

当院標準

当面は、6・14・22時の測定と、250 mL/回以上での医師コールを続けます。最新の指針を踏まえて、測定をやめるかどうかを院内で検討しています。当院

落とし穴

250 mL/回を超えても、嘔吐・腹部膨満・腹痛・画像・乳酸が落ち着いていれば、胃残だけでENを止めないでください。日本版2016・ESPEN 2023 の目安は 500 mL で、当院の 250 mL はそれより低い値です。250 mL は「減速して相談する合図」と考えます。胃残が続けて多いときは、蠕動促進薬 → 幽門後投与へ進みます。

  3. 緩下剤・蠕動促進薬を見直す
  4. 画像を確認する
  5. 整腸剤（ミヤBMなど）・止痢薬・五苓散を検討する

§9栄養剤の基礎知識

この章では、栄養剤の分類と、選ぶときの考え方を整理します。当院の標準はペプタメン（消化態）ですが、その理由は「消化態だから」ではありません。

9-1. たんぱく質の形で4種類に分かれる

栄養剤は、窒素源（たんぱく質がどこまで分解されているか）で分類します。分解が進むほど消化の手間は減りますが、浸透圧が上がり、味は落ちます。

§14急性膵炎

この章では、急性膵炎の栄養を決めます。かつての「膵臓を休ませるために絶食」は現在の標準ではありません。急性膵炎の膵臓は食事の刺激にほとんど反応せず、早く腸を使うほうが感染合併症を減らせると考えられています。

14-1. 重症度ごとの方針

要点
  • 膵炎を理由に絶食にしない
  • 軽症：24〜48時間以内に、低脂肪の固形食から
  • 重症・人工呼吸中：一般原則どおり、経鼻胃管からEN
  • PNは、ENができないときだけ
  • 成分栄養は選ばない。標準の栄養剤でよい

当院の運用（案）
  1. 膵炎を理由に絶食にしない。開始基準は §2 と同じ
  2. 経口ができる患者は、低脂肪の固形食から。腹痛や膵酵素の値を開始の条件にしない

  4. NGで耐えられなければ、W-EDでNJへ

§15急性胆管炎・胆道閉塞

この章では、急性胆管炎の栄養を決めます。急性胆管炎に特化した栄養療法の RCT や推奨は見当たりません。以下は、ICU栄養の一般原則と、ドレナージのタイミングを組み合わせた運用です。

15-1. 治療の中心はドレナージ

15-2. 栄養の運用

当院の運用（案）
  1. 胆管炎を理由に絶食にしない。開始基準は §2 と同じ（ショックが落ち着くまでは待つ）
  2. 絶食はドレナージの前後だけにする。処置前の絶食時間は院内の規定に従い、終わったらその日のうちに再開を目指す
  3. 処置まで1〜3日ある中等症で、「処置待ち」のために何日も絶食にしない。処置の日の朝だけ止める運用を消化器内科と決める
  4. ドレナージ後に循環が落ち着けば、経口できれば経口、できなければNGからEN
  5. 絶食が長引いてENが入らないときは §8 のPNに従う

15-3. 外瘻中の注意

落とし穴
  • 外瘻（ENBD・PTBD）で胆汁が体外に出ているあいだは、水・Na・重炭酸が失われます。排液量を記録して補ってください。
  • 胆汁が腸に届かないあいだは、脂肪と脂溶性ビタミンの吸収が落ちます。下痢・脂肪便に注意してください。
  • 外瘻の胆汁を腸に戻す（胆汁返還）かどうかは、消化器内科と相談してください。

§16症例の解決

NAD 0.12 μg/kg/分で乳酸が改善しているので、循環は開始基準を満たします。腸蠕動音が聞こえないことは開始を妨げません。一方、10日以上の摂食不良は表6の「1つ以上」に、BMI 17.5 は「2つ以上」の項目に当てはまり、リフィーディング高リスクです。

入室48時間以内に、経鼻胃管からリフィーディング予防プロトコール（ペプタメンインテンス、医師指定の低速で開始、5 mL/時ずつ増量）を選び、ビタメジンを1週間投与し、開始後72時間は P・Mg・K を毎日確認します。NAD が 0.1 μg/kg/分以上のあいだは増量を見合わせ、腹部膨満や乳酸の再上昇があればENを止めて腸管虚血を評価します。
