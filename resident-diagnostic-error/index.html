ICUの診断エラー

診断の3ステップのどこで誤るか：4つのバイアス、速い思考と遅い思考、診断のタイムアウト、仕組みで減らし振り返る

本稿の目的は、ICUで受け持つ患者の診断が、どこで、なぜ外れるかを知り、外れかけたときに立ち止まって診断をやり直せるようになることです。

持ち帰ってほしいことは3つです。1つ目は、診断の3ステップ（仮説を立てる → 情報を集める → 統合する）には、それぞれ入り込みやすい思い込みの癖（バイアス）があることです。2つ目は、「絶対これだ！」と思ったときと、予想どおりに良くならないときこそ立ち止まり、3つの問いで遅い思考に切り替えることです。3つ目は、診断エラーを個人の注意不足で片づけず、申し送り・人員・情報の流れといった仕組みの側から減らし、剖検やM&Mで振り返ることです。

構成は1人の患者の経過に沿って、「夜の入室 → 最初の見立て → 4つのバイアス → 速い思考と遅い思考 → 朝の回診で立ち止まる → 仕組みの要因 → チームと仕組みで減らす → 振り返る」と進みます。症例は架空です。

同じ患者でも医師ごとに判断がばらつく「ノイズ」、予測モデルとAIの読み方はICUの判断はなぜ外れるか、ショックの評価に使う心エコーはPOCUSで扱います。

§2最初の見立て

診断は、症候からそれを説明できるストーリー（病態生理の筋道）を複数挙げ、情報を集めて、もっともらしいものを選ぶ作業です。ICUでは、この作業が前の場所で付いた病名から始まりやすくなります。

2-1. 診断の3ステップ

診断は、仮説を立てる → 情報を集める → 統合する、の3ステップで進みます（図1）。仮説を立てるステップは、候補を挙げることと、その中から1本を選ぶことの2つに分かれます。挙げなかったストーリーは、診断できません。

ICUの患者は、救急外来・病棟・手術室で付いた病名と一緒に届きます。この患者では「尿路感染による敗血症性ショック」です。申し送りの病名は、前の人が選んだ1本のストーリーです。ICUの診断エラーは1回の判断より、申し送りや転棟をまたいで現れることが多いとされます（§6-3）MartinDelgado ICM2026。

2-2. 診断エラーとは

診断エラーは「誤診」より広い言葉です。米国医学アカデミー（2015年）の定義では、患者の健康問題について正確で適時な説明を確立できないこと、またはその説明を効果的に伝えられないことを指しますMartinDelgado ICM2026。

正しい診断に至っても、それが次のチームに伝わらなければ診断エラーです。正確または適時な診断に到達する機会を逃したこと、と言い換えることもできますValentin ICM2025。向きは3つあります。あるべき診断に届かない過小診断、違う診断に至る誤診、そして症状も害ももたらさなかったはずの状態を見つけて治療してしまう過剰診断です。ICUでは過剰な検査から過剰診断が起き、不要な治療・薬の毒性・侵襲的な手技・心理的な負担・費用の増加を通じて、見落としと同じくらい有害になりえますMartinDelgado ICM2026。この資料で使う言葉を表1にまとめます。

3-3. 利用可能性バイアス

候補を挙げるときに起きます。最近見た病気、印象に残った病気ほど頭に浮かびやすく、浮かんだものから候補の枠が埋まっていきます。

3-4. アンカリング

候補から1本を選ぶときに起きます。アンカーは船のいかりです。最初の印象に、いかりを下ろしたように引きずられます。自分の第一印象だけでなく、申し送りの病名も同じです。

仮説を立てる：1本を選ぶアンカリング
ICUでの典型例
救急外来から敗血症性ショックの診断で入室した患者で、敗血症の治療を続け、心原性ショックを明らかにしたはずの心エコーを行わないMartinDelgado ICM2026この患者：「尿路感染による敗血症性ショック」の申し送りが、そのまま夜の作業診断になった
なぜ起きるか
新しい証拠が出ても、最初の診断や最初に得た情報に重みを置きすぎるためですMartinDelgado ICM2026。ICUの診断は前の場所で付いた病名と一緒に届くので、継ぎ目で付いた病名がそのまま走りやすくなります（§6-3）
気づくための問い
最初の印象や申し送りを、自分の目で確かめた？
対策
申し送りの病名は、前の人が選んだ1本のストーリーとして受け取り、病歴と身体所見を自分で取り直します。ショックの原因を見直すときは心エコーで確かめます。ショックの患者1,015例の前向き研究では、エコーを受けた患者の54%で診断の不確かさが減るか治療方針が変わり、閉塞性ショックでは75%、心原性ショックでは58%でしたFlower ICM2024

3-5. 確証バイアス

情報を集めるときに起きます。自分の仮説に合う情報ばかりを探し、合わない情報を軽く扱います。聞かなければ、合わない情報は入ってきません。

3-6. 早期閉鎖

統合するときに起きます。もっともらしい1本が見つかると、そこで考えるのをやめてしまいます。

§4速い思考と遅い思考

4つのバイアスは、速い思考の近道が裏目に出たものです。立ち止まることは、遅い思考を起動することです。

4-1. 2つの思考

心理学者のカーネマンは、人の思考を2つに分けて説明しました。システム1は直感とパターン認識による速い思考、システム2は一つずつ確かめる遅い思考です（図6）MartinDelgado ICM2026。

ベッドサイドで「何かおかしい」と感じるのはシステム1、バイタルと経過を一つずつ照らし合わせるのはシステム2です。経験を積んだ集中治療医の強みはシステム1にあります。ヒューリスティクス（判断の近道）には不確かな状況で速い判断を助けるものもあり、危ないのは、分析と見直しで釣り合いを取らないときですMartinDelgado ICM2026。

ICUは、システム1に頼らざるを得ない場所です。疲労・ストレス・頭の過負荷・時間の切迫に加えて、騒音・アラーム・中断・過密が、分析より直感を先に立たせますMartinDelgado ICM2026。

4-2. バイアスは近道の裏目

§3の4つのバイアスは、どれも速い思考の近道です（図7）。近道はふだんは役に立ち、ときに外れます。

速い思考そのものは悪くありません。ただ、経験を重ねるだけで直感が当たるようになるとは限りません。直感が育つには、はっきりした早いフィードバック、予測と結果の安定した関係、それを学ぶ機会が要り、ICUではこれがそろわないことがあります。経験豊富な医師のICU死亡の予測は、医学生より有意に正確とはいえませんでしたPeringa CritCare2025。直感を磨く振り返りは§8で扱います。

この患者の夜は5つ目（入室が重なった当直）に当たり、朝8時30分の回診は3つ目に当たります。切り替えのスイッチは、図5の3つの問いです。

§7チームと仕組みで減らす

改善の重心は、個人へのバイアス教育よりも、文化・手順・情報の設計にありますMartinDelgado ICM2026。認知の側の対策と仕組みの側の対策を組み合わせますValentin ICM2025。

7-1. 申し送りで仮説を渡す

診断エラーの定義には、伝える失敗が含まれます。構造化された申し送りと多職種のチームワークは、コミュニケーションの失敗を減らす対策として挙げられていますMartinDelgado ICM2026Valentin ICM2025。

申し送りの病名は、前の人が選んだ1本のストーリーです。受け取る側が確かめられるように、病名を確定した事実としてではなく作業診断として渡し、何で確かめたかと、まだ確かめていないことを添えます。この患者なら「尿路感染による敗血症性ショックとして治療中。根拠は尿の所見。腹部の画像はまだで、腹部の診察はあいまい」です。

7-2. 多職種と家族

患者が話せないとき、家族は価値のある臨床情報の源ですMartinDelgado ICM2026。この患者の診断を変えたのも、家族の一言と、看護師の気づきでした。

チームでの症例の見直しや専門医のセカンドオピニオンといった多職種のレビューも、診断エラーを減らす対策に挙げられていますValentin ICM2025。見立てが割れていることは隠さず、話し合う材料にします。敗血症性ショックの2,233例では、最初の48時間にショックの原因の記載が医師の間で食い違ったのは9.5%でした。血液培養が陽性の患者では、食い違いがあるとICU死亡が多い傾向があり（調整OR 1.99、95%CI 0.98〜4.01）、この関連は治療までの時間では説明されませんでしたRao CritCare2026。

7-3. チェックリスト

チェックリストは、立ち止まる手順を頭の外に置く道具です。ICUのチェックリストの研究167本をまとめたスコーピングレビューでは、いちばん多い種類は回診のチェックリスト（52本）でしたErikson CritCare2023。

有意だった臨床アウトカムの90.3%（72件中65件）は改善の方向でしたが、研究の45%は導入前後の比較で、ランダム化は4%でした。導入後のデータで中身を直した論文は123本中8本だけで、回診と申し送りのチェックリストにはガイドラインがありませんErikson CritCare2023。診断のための問いは、図5の3つ程度に短く絞り、使ってみて直していきます。

7-4. 検査の使い方

検査を増やすほど安全、とは限りません。過剰な検査は偽陽性と過剰診断を生み、不要な治療と侵襲につながります。検査を適切に選ぶことを、診断スチュワードシップと呼びますMartinDelgado ICM2026。

臨床の基準そのものにも限界があります。剖検と比べると、胸部X線の浸潤影に白血球増多・発熱・膿性の気道分泌物のうち2つを合わせた肺炎の基準は、感度64.8%・特異度36%でしたTejerina CCM2012。「本当にVAPか」と問うのは、見落としだけでなく過剰診断を防ぐためでもありますContou ICM2026。

7-5. AIは診断を助ける道具

AIを使った意思決定の支援は、その場での示唆や鑑別の整理で診断エラーを減らす可能性がありますが、重要な限界も残りますValentin ICM2025。

AIは単独ではなく、頭の過負荷・情報の分断・アラート疲労を減らす仕組みの設計とセットで語られていますMartinDelgado ICM2026。AIの時代にも、診断は好奇心・粘り強さ・謙虚さと、問うことをやめない姿勢にかかっていますContou ICM2026。AIの出力を判断にどう入れるかはICUの判断はなぜ外れるかで扱います。

§8振り返る

ICUは、自分の診断が正しかったかが返ってきにくい職場です。振り返りを仕組みにして、学びの回路を閉じます。

8-1. フィードバックが返らない

患者は転棟・転院・死亡で目の前からいなくなり、診断の答え合わせが臨床医に返ってきません。診断の正しさについてのフィードバックが乏しいこと自体が、遅れや見逃しのリスクを高めますMartinDelgado ICM2026。

§4-2で見たとおり、直感が育つには早いフィードバックが要りますPeringa CritCare2025。ICU退室後のフォローアップ外来は、診断の乖離を見つけてICUのチームに返す機会になりますValentin ICM2025。

日米の医療者を職種・診療科・経験年数でそろえて比べた調査では、重大なエラーの後に職を辞めることを考えると答えたのは日本30.8%、米国8.6%でした。日本の医療者は罪責感（94.6%対61.6%）が強いのに、実際に同僚と話す割合は低くなっていました（48.6%対61.1%）Takatani CritCare2026。著者らは、義務にしたチームでのデブリーフィングのように、助けを求める負担を個人から仕組みに移す設計を勧めていますTakatani CritCare2026。この患者の当直医にも、振り返りの前に話を聞く場が要ります。
