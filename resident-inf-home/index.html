① VAP（人工呼吸器関連肺炎）と予防 →

ICU の患者は、病気そのものに加えて、私たちが入れた管（気管チューブ、中心静脈カテーテル、尿道カテーテル）と、私たちが使った薬（抗菌薬、ステロイド、免疫抑制薬）から感染を起こします。この教科書は、ICU で出会う感染症のうち、集中治療医が自分で予防し、診断し、治療を決める場面の多い6つを、教科書の章立てでまとめたものです。

読者は集中治療を学ぶ医師と看護師です。初めて読む人にも分かるように、言葉の意味、病気が起きる仕組み、検査が何を見ているかを先に説明し、そのあとに治療を書きます。文献だけをもとに書き、施設ごとの運用は載せていません。

初めて読む人へ：この教科書は、この Home と6つの章でできています。まず ① VAP から読むと、どの章にも出てくる「定義と疫学 → 病態 → 危険因子 → 診断 → 治療 → 予防 → ICU での落とし穴」の流れがつかめます。抗菌薬の選び方の基礎は、既存の講義 敗血症の診断・抗菌薬・感染源管理 と 重症患者の抗菌薬PK／PD にあるので、この教科書では総論と抗菌薬の章を置いていません。

この教科書の読み方

どの章も同じ順番で書いています。病気を知る（定義と疫学、病態）、見つける（危険因子、診断）、治す（治療）、起こさない（予防）の順です。最後に、ICU で起きやすい判断の誤りを「ICU での落とし穴」の表にまとめています。

  1. 病気を知る定義と疫学で「何をその病気と呼ぶか」を決め、病態で「なぜ起きるか」を図で押さえます。診断と予防の理由は、すべて病態のどこかにつながっています。
  2. 見つけて治す危険因子で疑い、検査が何を見ているかを知ったうえで結果を読みます。治療は、薬の選び方、期間、感染源（管）をどうするかの3つで考えます。
  3. 起こさない予防は、入れない、早く抜く、正しく扱うの3つが土台です。最後の「ICU での落とし穴」で、よくある判断の誤りと避け方を確かめます。

本文の数値には、出典の札を付けています。各章の終わりに文献の一覧（著者、誌名、年、DOI）を載せています。表と図で使う略語は、そのすぐ下に注を付けています。教科書全体の略語は、この Home の 略語 にまとめました。

薬の用量は、ICU での判断に直接かかわるものだけを、日本の添付文書で確かめたうえで載せ、論文での使い方と違うときはその違いを書いています。

各章の案内

①〜③は、私たちが入れた管から起きる感染です。④は抗菌薬を使った後に起きる感染、⑤は宿主の免疫が変わったときの感染、⑥はどの章にも出てくる耐性菌を薬の側から整理する章です。札から各章を開けます。

①VAP（人工呼吸器関連肺炎）と予防読める

定義と疫学、病態（誤嚥とバイオフィルム）、危険因子、診断の難しさ、検体の採り方、治療と期間、予防のバンドル

読む順：最初に（ICU で最も多い院内感染）

 ②カテーテル関連血流感染（CRBSI）読める

CRBSI と CLABSI の定義、入り口（外側と内腔）、危険因子、血液培養の採り方と DTP、抜くか残すか、菌ごとの治療、予防

読む順：①と並べて

 ③カテーテル関連尿路感染症（CAUTI）読める

定義と無症候性細菌尿、バイオフィルム、危険因子、尿検体の採り方、治療と期間、カテーテルの交換、入れない工夫

読む順：②の次に（無症候性細菌尿を治療しない理由）

 ④CD腸炎（Clostridioides difficile 感染）読める

芽胞から毒素まで、危険因子と PPI、2段階検査、重症度、初回と再発の治療、劇症と外科、FMT、感染対策

読む順：抗菌薬を使った後に起きる感染として

 ⑤免疫不全の感染症読める

免疫の穴と病原体の対応、移植や化学療法からの時期で絞る、診断の進め方、侵襲性真菌症、ニューモシスチス、CMV と呼吸器ウイルス、呼吸不全。好中球減少と移植後の管理は血液腫瘍の教科書へリンク

読む順：①〜④を読んだ後に（宿主が変わると何が変わるか）

 ⑥耐性菌読める

耐性の言葉（MDR、XDR、DTR）、4つの耐性の仕組み、保菌と感染、迅速検査、菌ごとの薬の選び方（ESBL と AmpC、CRE、緑膿菌、CRAB、MRSA と VRE）、日本で使える新しい抗微生物薬（ザバクサなど）、広げない工夫

読む順：最後に（①〜⑤の菌をまとめて薬で整理）

読む順は ①→②→③→④→⑤→⑥ を勧めます。①〜③の3つの管の感染は、どれもバイオフィルム（管の表面に菌が作る膜）が起点になるので、続けて読むと共通点が見えます。⑥は①〜⑤で出てきた菌をまとめて扱うので、最後に読むと整理できます。

各章で学ぶこと

表1｜6つの章の一言紹介
章この章で答える問い関連する講義
① VAP確定診断の方法が無い肺炎を、どこまで疑い、どの検体で確かめ、何日で治療を終えるか。予防のバンドルのうち、何が効き、何をやめるか。VAPと抗菌薬、人工呼吸器関連合併症
② CRBSI発熱した患者のカテーテルを抜くか残すかを、何で決めるか。血液培養をどこから何本採り、菌ごとに何日治療するか。ライン・カテーテル、敗血症の抗菌薬
③ CAUTIカテーテル尿から菌が出たとき、治療するのはどんな場合か。尿をどこから採り、カテーテルをいつ替え、いつ抜くか。敗血症の抗菌薬
④ CD腸炎ICU の下痢で、誰に CD の検査を出し、陽性をどう読むか。初回と再発で薬をどう変えるか。劇症になったら何を入れ、いつ外科を呼ぶか。ストレス潰瘍予防、栄養
⑤ 免疫不全の感染症どの免疫が欠けると、どの病原体が来るか。移植や化学療法からの時期で、原因をどう絞るか。真菌、ニューモシスチス、ウイルスをどう診断するか。好中球減少と移植後の管理は、血液腫瘍の教科書の章へリンクして分担します。血液腫瘍の教科書 ⑥、⑦
⑥ 耐性菌耐性の仕組みを知ると、なぜ薬の選び方が変わるのか。保菌と感染をどう分け、菌ごとにどの薬を選ぶか。日本で使える新しい抗微生物薬（ザバクサなど）を、酵素の型でどう使い分けるか。広げないために何をするか。抗菌薬PK／PD、敗血症の抗菌薬

略語：VAP＝人工呼吸器関連肺炎、CRBSI＝カテーテル関連血流感染、CAUTI＝カテーテル関連尿路感染症、CD＝Clostridioides difficile、PK／PD＝薬物動態と薬力学。
