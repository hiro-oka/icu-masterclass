1症例 — 40代男性、GCS 7、舌根沈下と吐物詳しく

  • 向精神薬の過量服薬。GCS 7・舌根沈下・吐物を出せない・PaCO₂ 56・予測体重66 kg。判断の順番が章の順番：挿管するか（§2）→ 初期設定（§4）→ 血液ガス（§5）→ アラーム（§6）。§3は設定の前にしくみを確かめる章

2挿管の適応は「ABCDE」 — この患者はAとDで挿管詳しく

  • Airway（気道閉塞・舌根沈下・喀痰を出せない）・Breathing（低酸素・高CO₂・呼吸仕事量の増大）・Circulation（ショック）・Disability（意識障害による気道閉塞・クリアランスの低下）・Everything else（今後挿管が必要になりそう・検査・緊急手術）を、気道から順に見る
  • この患者：A（吐物を出せない）とD（GCS 7で気道を開けておけない）で挿管。GCSの値だけでは決めない。Bで挿管を避ける手段を試すなら、失敗の基準（HFNCはROX、NIVはHACOR）を先に決める
  • 補足：同じ原稿はMOVES・3質問法でも挙げているが、見ている項目はほぼ同じ。抜管前の「ABC-Drs.」（付録）と対で覚える

3人工呼吸器のしくみ — 圧の差が流量を生み、3T'sでモードが決まる詳しく

  • 運動方程式：気道内圧＝R×流量（流す分）＋量÷C（膨らませる分）＋PEEP
  • 1呼吸の5つの場面（①呼気終末 → ②吸気の始まり → ③吸気の途中 → ④呼気の始まり → ⑤呼気）：流量＝（回路の圧 − 肺胞の圧）÷ R。差が埋まる速さτ＝R×Cは、正常0.5秒・ARDS 0.2秒（すぐ埋まる）・COPD 1.8秒（埋まりきらず吐き残しが積み上がる＝auto-PEEP）

  • 見分け方：圧の立ち上がり直前のへこみ＝患者トリガー。PSVの終了の％は、当院のHamilton C6ではETS、PB840ではEsens（既定はどちらも25%）。％を上げると吸気が短く呼気が長くなり（COPDで呼気を確保）、下げると吸気が長くなる（早すぎる終了・二度吸いを防ぐ）

5血液ガスで直す — 酸素化はFiO₂とPEEP、CO₂は肺胞換気量詳しく

  • 2つのつまみ：酸素化はFiO₂と平均気道内圧（主にPEEP）、CO₂は肺胞換気量＝（VT − 死腔）× 呼吸数（浅く速いほど死腔の割合が増え、CO₂が出にくい）。PEEPは静脈還流を下げ右室後負荷を増やす（益と害は同じ機序の裏表）。目標は正常値ではなく、PaO₂ 60〜90・PaCO₂ 60未満を最小限の害で
  • この患者：挿管30分後、FiO₂ 0.6でpH 7.24・PaCO₂ 60・PaO₂ 63（P/F 105）。分時換気量5.6 L/分でも肺胞換気量は3.5 L/分 → PEEP 5 → 10、呼吸数14 → 18。1時間後はpH 7.35・PaCO₂ 46・P/F 160。VTを480 mLに上げるとΔP約15.5で目安を超える
  • 比べ方：酸素化はP/F比（PaO₂ ÷ FiO₂）で（PaO₂ 150・FiO₂ 1.0は、PaO₂ 100・FiO₂ 0.3より悪い）。呼吸数を上げたら呼気が短くなるので、呼気フローが0に戻ってから次の吸気かを見る（戻る前ならauto-PEEP）

6アラーム対応 — 高圧はPIPとPplatで分け、低圧は回路をたどる詳しく

  • 鳴ったら波形より先に患者：0分 ベッドサイド（胸郭・SpO₂・血圧・チューブと回路）→ 〜2分 波形 → 〜5分 ポーズとホールド → 〜10分 設定を1つだけ → 〜30分 上級医へ。急変はまずDOPE（位置異常・閉塞・緊張性気胸・器械）
波形の動き意味（この患者）
PIPだけ上がる気道抵抗の上昇（翌日 PIP 41・Pplat 22 → 噛みつきと痰）
PIPとPplatが上がるコンプライアンスの低下（3日目 PIP 37・Pplat 31 → 片肺挿管）
PCVで換気量が増減圧は変わらず、流量と換気量に出る（換気量の下限アラームで気づく）
低圧・換気量の低下回路の外れ・カフ漏れ・計画外抜管を、チューブ・カフから本体へ順にたどる

7ARDSとCOPD — ARDSは伸ばしすぎない、COPDは吐かせる詳しく

  • ARDS：換気される肺（baby lung）が小さいので、VT 6（4〜8）mL/kg PBW・Pplat 30未満・ΔP 15未満。PEEPの選び方・腹臥位などはARDSの資料で
  • COPD・喘息：呼吸数10〜12・I:E 1:2〜1:4・吸気流量60〜100 L/分で呼気時間を取り、pH 7.25〜7.30まで許容。PEEPは初期5、auto-PEEPが分かればその50〜80%まで、Pplatが上がったら止める。auto-PEEPは呼気ポーズで測る

付録波形を読む順番・非同調・離脱と抜管詳しく

  • 読む順番：呼気フロー → 吸気フロー → 吸気圧 → トリガー → サイクル。滑らかな減衰は患者が休んでいる手がかり。調節換気から補助換気へは早めに（P/F 150超で検討、PEEP 8以上なら200程度）
  • 非同調：ダブルトリガー（2回分が入る）は鎮静の前に呼気終末ホールド。無呼吸ならリバーストリガー（鎮静を浅く）、努力が見えれば吸気時間・サポートを延ばす。無効努力は総PEEPを測ってから、フロー不足（吸気中に圧がへこむ）は流量を上げる
  • 離脱は毎日SATからSBTへ：SATで鎮静薬を止めて覚醒を確かめ（鎮痛薬は続ける）、SBTはPSV 5〜8・PEEP 5 cmH₂Oで30分（回路は外さない。文献ではPEEP 0やTピースも）。通らなければすぐ元に戻し、原因を直して原則翌日また試す
  • Airway：上気道の狭窄が少ない
  • Breathing：努力呼吸がない
  • Circulation：循環が安定
  • Dys CNS：指示に応じる
  • Reflex：咳が十分に出る
  • Sputum：痰を自分で出せる

抜管前の「ABC-Drs.」：A・D・R・Sは主に気道、B・Cは離脱の失敗を見る。FiO₂≦0.4・RSBI＜105は参考
