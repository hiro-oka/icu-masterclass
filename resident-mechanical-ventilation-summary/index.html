1症例詳しく

  • 40代男性、向精神薬の過量服薬による意識障害。身長170 cm（予測体重66 kg）。A：舌根沈下、口腔内の吐物を自力で喀出できない。B：リザーバーマスク10 L/分でpH 7.13・PaCO₂ 90・PaO₂ 80・HCO₃⁻ 29（急性の呼吸性アシドーシス）。D：GCS 7（E1V2M4）。循環はショックの徴候なし。右下肺野の浸潤影は誤嚥を疑う

2挿管の適応 — ABCDE詳しく

  • 単一の数値で決める基準はない。Airway（気道閉塞・舌根沈下・喀痰の喀出困難）・Breathing（低酸素・高CO₂・呼吸仕事量の増大）・Circulation（ショック）・Disability（意識障害による気道閉塞・気道のクリアランスの低下）・Everything else（今後の挿管の必要性・検査・緊急手術）を、気道から順に評価する
  • この患者：AとDだけで挿管の適応があり、Bにも該当（C・Eはなし）。意識障害と嘔吐があるのでNIVは使えない

3モードと波形詳しく

  • モードの選び方：自発呼吸がなければVCV（量制御）かPCV（圧制御）だけ、あればPSV（圧支持）を含めどれも選べる。挿管直後は自発呼吸が不確かなのでVCVかPCV（転帰の差はなく、慣れたほう）。この患者はVCV。PSVへは、呼吸ドライブが安定・同調・過剰な吸気努力なし・換気量を自力で保てるときに移る（無呼吸アラームとバックアップ換気を確認）

  • ETS／Esens（PSVの終了の％。当院のHamilton C6はETS、PB840はEsens、既定はどちらも25%）：数値を大きくすると吸気は短く、小さくすると長くなる。COPDや遅すぎる終了には上げ、早すぎる終了（二度吸い）には下げる
  • 気道内圧＝抵抗×流量（抵抗成分）＋換気量÷C（弾性成分）＋PEEP − Pmus。吸気ポーズで流れを止めたときだけ回路の圧＝肺胞の圧（Pplat）。この患者のPIP 24＝6＋13＋5
  • Flow＝（回路の圧 − 肺胞の圧）÷ R。差が縮まる速さはτ＝R×C（1τで約63%、3τで約95%）。正常0.5秒・ARDS 0.2秒・COPD 1.8秒（呼気が終わる前に次の吸気 → auto-PEEP）

5血液ガスに基づく設定修正詳しく

  • 2つの調整：酸素化はFiO₂と平均気道内圧（主にPEEP。PEEPは静脈還流の低下と右室後負荷の増大を伴う）、換気（CO₂）は肺胞換気量＝（VT − 死腔）× 呼吸数（浅く速いほどCO₂が出にくい）。目標は正常化ではなく、PaO₂ 60〜90・PaCO₂ 60未満を最小限の害で
  • この患者：挿管30分後、FiO₂ 0.6でpH 7.26・PaCO₂ 60・PaO₂ 63（P/F 105）。分時換気量5.6 L/分でも肺胞換気量は3.5 L/分。酸素化はP/F比（正常400〜500）で比べる → PEEP 5 → 10、呼吸数14 → 18（VTは400のまま。480 mLではΔP≈15.5）。1時間後 pH 7.35・PaCO₂ 46・P/F 160、PIP 28・Pplat 22・Cst 33、平均気道内圧 約8 → 約13

6アラーム対応詳しく

  • まずベッドサイドで患者を診る。SpO₂や血圧が急に落ちていれば、波形を読む前にDOPE（Displacement 位置異常・Obstruction 閉塞・Pneumothorax 緊張性気胸・Equipment 器械）。迷ったら回路を外して用手換気
波形の動き（基準：PIP 28・Pplat 22）意味（この患者）
PIPだけ上がる気道抵抗の上昇（翌日 PIP 41・Pplat 22 → R 19。噛みつきと痰）
PIPとPplatが上がるコンプライアンスの低下（3日目 PIP 37・Pplat 31 → Cst 19。片肺挿管）
PCVで換気量が減る圧は台形のまま、流量と換気量に出る（一回換気量・分時換気量の下限アラームで気づく）
低圧・換気量の低下回路の外れ・カフ漏れ・計画外抜管。チューブとカフ → 人工鼻・Yピース → 回路 → 本体の順（この患者は人工鼻とYピースの外れ）

7ARDSと閉塞性肺疾患詳しく

  • ARDS：換気される肺（baby lung）が小さいので、VT 6（4〜8）mL/kg PBW・Pplat 30未満・ΔP 15未満。PEEPの選び方・腹臥位・筋弛緩・ECMOはARDSの資料で
  • COPD・喘息：呼吸数10〜12・I:E 1:2〜1:4・吸気流量60〜100 L/分で呼気時間を確保し、pH 7.25〜7.30まで許容。総PEEP＝設定PEEP＋auto-PEEPで、呼気終末ホールドで測る。PEEPは初期5、auto-PEEPが分かればその50〜80%まで

8付録詳しく

  • 波形判読の手順：呼気フロー → 吸気フロー → 吸気圧 → トリガー → サイクル。非同調：ARDSで最も警戒するのはダブルトリガー。鎮静を追加する前に呼気終末ホールド（振れがなければリバーストリガーが濃厚 → 鎮静を浅くし設定を見直す）。ホールドだけで型を確定しない
  • Airway：上気道の狭窄の心配が少ない
  • Breathing：SBT中に努力呼吸がない
  • Circulation：循環動態が安定
  • Dys CNS：指示に応じられる
  • Reflex：咳が十分に出る
  • Sputum：痰を自分で出せる

抜管前の確認「ABC-Drs.」：単独の合否基準ではない。A・D・R・Sは気道の失敗、B・Cは離脱の失敗を見る。FiO₂≦0.4程度・RSBI＜105は参考
