1持ち帰る3点詳しく

SaO₂は分数で決まるECMO流量÷心拍出量。典型は80〜90%で、低くても呼吸器を上げない・VAに変えない
肺は休ませるPplat < 25・駆動圧 ≤ 15・PEEP ≥ 10。目標に届かなければ回路側（血流量・sweep）で対応する
CO₂を急に下げない最初の24時間でexcess CO₂を50%超下げず、48〜72時間で正常化する

2適応はEOLIA基準 — 「挿管から7日未満」を最初に聞く詳しく

  • 前提3つすべて：人工呼吸7日未満／FiO₂ ≥ 80%・VT 6 mL/kg PBW・PEEP ≥ 10で最適化済み／腹臥位と筋弛緩薬を試した
  • 生理学的基準のどれか1つ：P/F < 50が3時間超／P/F < 80が6時間超／pH < 7.25かつPaCO₂ ≥ 60が6時間超（呼吸数35/分まで上げたうえで）
  • 絶対禁忌は1つだけ：脱カニュレーションまでに回復が見込めないこと。年齢・免疫抑制・人工呼吸7日超は相対禁忌で、BMI > 40は禁忌ではない
  • 初日に家族へ：「時間を区切った試行」として、無益性による中止の可能性を開始前に伝える。重症ARDSの院内死亡29〜43%、支持期間は多くが9〜14日

4低酸素・回路トラブルは「流量を上げない」から詳しく

SaO₂が上がらない → 呼吸器を上げる前に、6つの原因を順に見る
▼
まず再循環
  • 脱血側SO₂ > 75%、SaO₂−脱血側SO₂ < 10%なら疑う
  • 流量を上げると有効流量がかえって減ることがある。先に落としてみて、カニューレの間隔と向きを見る
ほかの5つ
  • VO₂増大（発熱・不穏・シバリング）・高心拍出
  • 人工肺の機能低下・自己肺の悪化・Hb低値
▼
呼吸器設定を上げない・VAに変えない。PaCO₂が高ければsweepを、SaO₂が低ければ血流量と再循環を見る
  • 回路の圧で場所を絞る：脱血圧だけが大きな陰圧＝脱血不良（チャタリングの初手は回転数を下げる）／肺前後の差圧が開く＝人工肺の目詰まり／肺前も肺後も上がる＝送血側の閉塞
  • VV-ECMO中の心停止は胸骨圧迫が要る（VAとは逆）。ALSの前に回路を確かめる（空気混入・カニューレ抜去ならクランプ）
  • 自発呼吸が出たら測る：P0.1・Pocc（7〜15 cmH₂Oが安全域）。努力が強ければ原因を潰し、次にsweepを上げる。鎮静を足すのは最後

5離脱は血流量を保ったままガスだけ切る詳しく

  • 始めてよい条件：FiO₂ ≤ 60%・PEEP ≤ 10・PaO₂ ≥ 70、VT ≤ 6 mL/kg PBW・Pplat ≤ 28・呼吸数 ≤ 28、胸部X線の改善。溢水は先に整える
  • 3段：FDO₂を約20%刻みで0.21まで → sweepを0.5〜1 L/分刻みで1 L/分まで → sweep offで2〜3時間以上観察。血流量は一度も下げない
  • 判定：sweep offでPaO₂ ≥ 70・PaCO₂とpHが許容範囲・呼吸努力が増えない、の3つがそろえば抜去へ
  • 夜間に「PaCO₂がまだ高い」でsweepを上げない
  • 導入翌朝のX線でカニューレ先端の位置と間隔を見る
  • 毎日今日はどの相か（6相）をラウンドで決める
  • 抜去24時間後にDVTを評価する
